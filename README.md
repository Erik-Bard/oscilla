# oscilla

A very opinionated music player

## Develop

Requires Node and Rust ([Tauri prerequisites](https://v2.tauri.app/start/prerequisites/)).

```sh
npm install
npm run tauri dev    # run the app with hot reload
npm run tauri build  # build an installer
```
